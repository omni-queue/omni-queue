# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report vulnerabilities privately to:

- maintainers@vasto.dev

Include as much detail as possible:

- Affected package(s) and version(s)
- Impact and attack scenario
- Reproduction steps or proof of concept
- Suggested remediation, if available

## Response timeline targets

- Initial acknowledgment: within 3 business days
- Triage and severity assessment: within 7 business days
- Status updates: at least every 7 business days while active

## Coordinated disclosure

We follow coordinated disclosure and ask reporters not to publicly disclose issues until:

- a fix is available, and
- maintainers confirm disclosure timing.

## Scope

This policy covers security issues in this repository's maintained packages.

Out-of-scope examples:

- Vulnerabilities in unsupported third-party dependencies with no exploit path through this project
- Denial-of-service scenarios requiring unrealistic resource assumptions
- Issues in local development-only example code that do not affect package consumers
